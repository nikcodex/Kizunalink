<section class="kz-section not-content">
  <h2>Why KizunaLink?</h2>
  <p class="lead">Lavalink defined the protocol. KizunaLink keeps the protocol and replaces everything underneath it with a single static Rust binary built on <code>tokio</code>, <code>axum</code> and <code>symphonia</code>.</p>

  <div class="kz-grid">
    <div class="kz-card"><div class="icon">⚡</div><h3>Zero GC jitter</h3><p>No JVM, no garbage collector. Audio frames are scheduled by Tokio on a fixed 20 ms cadence with no stop-the-world pauses.</p></div>
    <div class="kz-card"><div class="icon">🪶</div><h3>~15 MB idle</h3><p>A stripped, LTO-optimised binary. Run it next to your bot on a 512 MB VPS — or on a phone with Termux.</p></div>
    <div class="kz-card"><div class="icon">🔁</div><h3>Lavalink v4 compatible</h3><p>Same REST routes, same WebSocket messages, same track encoding. Existing clients like Shoukaku, Wavelink and Lavalink4NET just work.</p></div>
    <div class="kz-card"><div class="icon">🎵</div><h3>Native 320 kbps</h3><p>Direct CDN stream resolution for JioSaavn, plus YouTube, Spotify, Apple Music, Deezer, SoundCloud and more — 12 sources built in.</p></div>
    <div class="kz-card"><div class="icon">🔐</div><h3>DAVE E2EE ready</h3><p>Implements Discord's DAVE end-to-end encryption protocol (MLS) via <code>kizuna-voice</code>, so you're ready when Discord enforces it.</p></div>
    <div class="kz-card"><div class="icon">🧰</div><h3>Batteries included</h3><p>Server-side queue, autoplay, loop, synced lyrics, Prometheus metrics, IP rotation, SSRF protection — no plugins required.</p></div>
  </div>
</section>

<section class="kz-section not-content">
  <h2>Up and running in 60 seconds</h2>
  <p class="lead">Pick your platform. Every path ends with a server listening on port <code>2333</code> that any Lavalink v4 client can connect to.</p>
</section>

<Tabs syncKey="install">
  <TabItem label="Linux (one-liner)">
    ```bash title="Terminal"
    curl -sL https://raw.githubusercontent.com/nikcodex/Kizunalink/main/install.sh | bash
    cd ~/kizunalink && ./kizunalink
    ```
  </TabItem>
  <TabItem label="Docker">
    ```bash title="Terminal"
    git clone https://github.com/nikcodex/Kizunalink.git && cd Kizunalink
    docker compose up -d
    ```
  </TabItem>
  <TabItem label="Termux (Android)">
    ```bash title="Termux"
    pkg install curl -y
    curl -sL https://raw.githubusercontent.com/nikcodex/Kizunalink/main/install.sh | bash
    cd ~/kizunalink && ./kizunalink
    ```
  </TabItem>
  <TabItem label="From source">
    ```bash title="Terminal"
    sudo apt install -y cmake libopus-dev   # build deps
    git clone https://github.com/nikcodex/Kizunalink.git && cd Kizunalink
    cargo build --release
    ./target/release/kizunalink
    ```
  </TabItem>
</Tabs>

Then point any Lavalink v4 client at it:

<Tabs syncKey="lang">
  <TabItem label="JavaScript" icon="seti:javascript">
    ```js title="bot.js" {5-9}
    import { Client, GatewayIntentBits } from 'discord.js';
    import { Shoukaku, Connectors } from 'shoukaku';

    const client = new Client({ intents: [GatewayIntentBits.Guilds, GatewayIntentBits.GuildVoiceStates] });
    const nodes = [{
      name: 'kizuna',
      url: 'localhost:2333',
      auth: 'youshallnotpass',
    }];
    const shoukaku = new Shoukaku(new Connectors.DiscordJS(client), nodes);
    shoukaku.on('ready', (name) => console.log(`⛩️ ${name} connected`));
    client.login(process.env.DISCORD_TOKEN);
    ```
  </TabItem>
  <TabItem label="Python" icon="seti:python">
    ```python title="bot.py" {9-12}
    import discord, wavelink
    from discord.ext import commands

    class Bot(commands.Bot):
        def __init__(self):
            super().__init__(command_prefix="!", intents=discord.Intents.all())

        async def setup_hook(self):
            node = wavelink.Node(
                uri="http://localhost:2333",
                password="youshallnotpass",
            )
            await wavelink.Pool.connect(nodes=[node], client=self)

    Bot().run("DISCORD_TOKEN")
    ```
  </TabItem>
  <TabItem label="curl" icon="seti:shell">
    ```bash title="Terminal"
    curl -H "Authorization: youshallnotpass" \
      "http://localhost:2333/v4/loadtracks?identifier=ytsearch:never%20gonna%20give%20you%20up"
    ```
  </TabItem>
</Tabs>
