## How to use the output

- **`config.toml`** — save next to the binary (or mount over `/app/config.toml` in Docker). Contains everything except credentials.
- **`.env`** — save next to the binary. Loaded automatically; overrides the file. Holds the password and any source credentials.
- **`docker-compose.yml`** — a complete Compose service that builds from the GitHub repo. Pair it with the generated `config.toml` in the same folder.

See the [config.toml reference](/configuration/config-toml/) and [environment variables](/configuration/environment/) for what each key does.
